# SELA

Mobile Flutter application for SELA.

## Requirements

- Flutter stable
- Dart SDK compatible with `sdk: ^3.11.0`

## Setup

1. Create a `.env` file in the project root.
2. Provide the required keys such as Supabase and Gemini credentials.
3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```
